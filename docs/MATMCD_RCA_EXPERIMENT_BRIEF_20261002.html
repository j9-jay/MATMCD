10Findings — 부정확한 입력·해석

순위 변화의 단일 원인 확정은 불가. 확인된 문제와 가능한 영향 구분.

확인된 문제간단한 실제 예시가능한 영향
장애 근거 누락MongoDB 요약에 No space left on device 존재 → 검색 문맥·최종 노드 정보에서는 부재핵심 장애 신호 없이 역할·일반 지식 중심 판단
현재 질문과 다른 쌍의 문장 재사용MongoDB→Latency 질문에 amq-streams→apiserver 판정 문장 잔존현재 관계와 무관한 설명으로 유도
그래프 방향 설명 불일치G[MongoDB, ratings]=1은 ratings→MongoDB. 프롬프트는 반대 방향으로 서술초기 구조에 대한 잘못된 해석 가능
근거 밖의 LLM 추정Kafka Streams→MongoDB 데이터 경로, Latency를 P99 등으로 추정확인되지 않은 시스템 지식이 판단에 혼입
후보 축소정답 MongoDB는 포함, reviews·productpage 등 전파 경로 후보는 제외전체 서비스의 원인 경로 보존 불확실
