# 연구 로드맵 — 추론 상태 기반 근거 검색 (NLP/RAG)

2026-10-18 개정. 현재 작업은 [TASK_070](../tasks/TASK_070_state_aware_retrieval_experiments.md)이다.

근거 자료: 연구 아이디어와 구현·실험 계획 PDF(`E:/연구/Reasoning-State-Aware Evidence Retrieval for Microservice Incident Analysis*.pdf`), MATMCD 논문(ACL Findings 2025), [30 Pod 결과 보고서](RCA_ORACLE30_RESULT_REPORT_20260927.md), [LEMMA 기준선 종료 기록](../tasks/TASK_069_blind_baseline.md).

## 방향

- 연구 분야는 **NLP/RAG**다. 목표 학회는 ACL, EMNLP, NAACL, EACL, COLING이다.
- 과제를 **"다단계 추론에 필요한 이질적 근거의 검색과 귀속(attribution)"**으로 정의한다. RCA 정확도와 인과 그래프 정확도는 하류 지표로 함께 보고한다.
- 방법은 도메인 독립적으로 정의하고, 장애 분석(카테고리 1)과 인과 발견(카테고리 2)에서 검증한다.

## 방법 정의

MATMCD의 고유 아이디어(DA-AGENT의 반복 검색·요약, CC-AGENT의 2단계 판단)는 쓰지 않는다.

```text
[오프라인] 기존 데이터(로그·trace·메트릭 요약 / 웹 문서 스냅샷) → 근거 단위 → 역할·상태 태그 → corpus
[질의 시]  주제 인식 → 추론 상태 동적 생성 → 상태별로 필요한 역할의 근거만 검색 → 근거 인용과 함께 판단
[공통 출력부] 쌍별 Yes/No → 제약 PC → 그래프 → (장애 분석) RWR 순위
```

근거 역할(초안): System Structure / Observation / Diagnosis / Action. 이번 연구에서는 Action(복구 방법)을 제외한다.

### 동적 추론 상태 (D-4 후보)

| 방식 | 상태를 정하는 법 | 장점 | 위험 |
|---|---|---|---|
| A. 상태 유형 분류 | 작은 유형 목록(예: 대상 확인 / 연결 고리 / 속성 검증 / 비교·집계 / 충돌 해소 / 결론)에서 LLM이 현재 유형과 빠진 정보를 선택 | 통제·해석이 쉽고, RCA 고정 5단계를 특수 사례로 포함 | 목록 설계가 결과에 영향 |
| B. 근거 공백 기반 | 답안 초안에서 근거 없는 주장을 상태로 삼아 필요한 역할의 근거를 검색. 모두 뒷받침되면 종료 | 귀속 평가와 직결 | 주장 분해 품질에 의존 |
| C. 계획 그래프 | 하위 목표 그래프에 노드별 근거 역할 표기, 실패 시 재계획 | 다단계 QA에 자연스러움 | 호출 증가 |
| D. 데이터로 유도 | 개발 데이터의 하위 질문을 묶어 유형을 자동 생성 | 수작업 설계 불필요 | 해석이 어려움 |

권장안은 A + B 결합이다: 상태 = (상태 유형, 빠진 근거). 인과 발견의 쌍별 예시는 정의 확인 → 작용 메커니즘 → 시간 순서·방향 단서 → 교란·반대 근거 → 판단이다. 근거가 충분하면 건너뛰고 충돌하면 교란 확인으로 돌아간다. 고정 상태와 동적 상태를 ablation으로 비교하고 상태 경로를 기록해 해석 분석에 쓴다.
