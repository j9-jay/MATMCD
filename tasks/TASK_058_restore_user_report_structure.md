# TASK_058 - 사용자 지정 12개 항목을 유지한 보고서 기획서 재작성

## 목적

사용자가 거부한 7개 화면 중심 재구성을 대체하고, 사용자가 처음 제시한 1~12번 설명 순서를 유지하는 구체적인 집필 기획서를 작성한다. 이번 범위는 기획서이며 HTML 제작·수정은 포함하지 않는다.

## 작업 항목

- [x] 사용자 지정 12개 항목의 순서와 역할 복원
- [x] 각 절의 작성 내용·강조점·중심 시각·편집 경계 정의
- [x] 최초 구성과 후속 변경 구분 및 임시 전처리 시점 확인
- [x] 7~8번에서 문제·조치·조건 변화·영향의 설명 형식 반복
- [x] 임시 선택·미확정 사항 통합 표와 저자 회신 후 갱신 방침 작성
- [x] 결과·실측 시간·토큰의 범위와 사실/가설 구분
- [x] 자원 환경 이전을 우선 검토하는 향후 계획 반영
- [x] 12개 절 순서·출처 링크·HTML 무변경 검증

## 확인 사항

전문가 관점 리뷰에서 제안했던 구조 변경보다 사용자의 최신 명시 구조를 우선한다. 추가 전문가 리뷰나 HTML 개편은 이번에 수행하지 않았다. 실험·코드·조건·결과도 변경하지 않았다.

최초에 의도한 주요 로컬 대체 조건은 생성 LLM이지만, 임시 전처리 준비도 모델 설치 전부터 진행됐다. 따라서 LLM 외 모든 조건이 저자와 동일했다는 표현을 사용하지 않는다. 저자 메일은 사용자의 문의·회신 대기 설명을 반영하며 실제 발송 일시나 답변 내용을 새로 만들어 기록하지 않는다.

## 결과

[기획서 v3](../../PROFESSOR_RESEARCH_PROGRESS_REPORT_PLAN.md)를 같은 경로에서 다시 작성했다. 1~2 연구 아이디어/계획, 3~5 논문/RCA/시나리오, 6 최초 환경, 7~8 문제와 변경, 9 결과, 10 분석, 11 재현 요건, 12 향후 계획 순서다. 중요도에 따른 편집과 중복 방지 지침을 함께 작성했다.

검증: 번호가 붙은 본문 절은 정확히 1~12 순서, 로컬 출처 링크 누락 0. 기존 HTML SHA-256은 변경 전후 `6FBA4CEC935467D5275CED578B3ED115B7139A0F3E90C37BEC8BC996D7F06066`으로 동일하다. 기존 HTML은 새 기획서를 반영한 문서가 아니며 사용자 검토 전 상태로 그대로 두었다.
