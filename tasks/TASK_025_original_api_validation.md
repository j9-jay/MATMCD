# TASK_025 - 로컬 성과 확인 후 원본 API 조건 검증

## 목적
사용자 계획에 따라 로컬 실험 결과를 확인한 이후 원본 GPT·embedding·검색 서비스 조건을 별도로 구성하고 검증한다.

## 작업 항목
- [ ] TASK_018의 저자 답변 또는 공식 근거로 단계별 모델·snapshot·요약·검색 조건 확인
- [ ] 로컬에서 사용한 모델·양자화·tokenizer·thinking·sampling과 원본의 차이 대조
- [ ] Git 외부에서 자격정보를 연결할 구체적 설정 준비
- [ ] 사용 서비스·호출 범위·비용 한도에 대한 별도 승인
- [ ] 승인 후 최소 접근 검증
- [ ] MATMCD 기준선과 개선안 모두를 동일 API 조건으로 비교하는 실행안 준비
- [ ] 확정한 명령·입력·출력·평가 기준과 논문 표 4 비교 조건 기록

## 확인 사항
- TASK_023의 로컬 대체는 원본 API 접근 문제의 해결이나 과금 승인이 아니다.
- 논문 GPT-4o mini 설명과 공개 코드의 gpt-4·최종 라이브러리 기본 모델 차이는 유지한다. 임의 통일하지 않는다.
- API 응답·모델 접근·현재 제공 여부는 아직 검증하지 않았다. 당시 snapshot 및 검색 자료를 다시 확보할 수 있다는 보장도 없다.
- 로컬에서 개선이 관찰되어도 API 모델에서 같은 방향일지는 별도 검증 대상이다.
- 모델 교체 시 기준선과 개선안 양쪽을 다시 평가한다. 기존 로컬 결과를 원 논문 재현 결과로 명명하지 않는다.

## 결과
사용자 요청에 따라 후속 검증으로 분리했다. 자격정보 탐색·유료 호출·메일 발송·실제 실험은 실행하지 않았다.
