# TASK_066 - HTML 발표자료 v3 전면 리디자인

## 목적

v2의 연구 논리·순서·수치·주요 의미를 보존하면서 긴 서술을 줄이고 16:9 발표용 HTML을 새로 작성한다. 기존 v1/v2와 Markdown 원고는 보존한다.

## 디자인 시스템 — 구현 전 결정

- Art direction: 편집 디자인 중심의 연구 발표. 종이색 배경, 먹색 텍스트, 청록 강조, 제한된 적갈색은 제약·미확정 표시용.
- 색상: background #F3F1EB, surface #FFFFFF, ink #182924, muted #65706A, accent #126957, secondary #A45F3C. 어두운 섹션 전환은 ink 배경.
- 캔버스: 1600×900 고정 16:9, 화면에 비례 축소. 상단 탐색과 하단 이동 제어는 캔버스 밖에 배치.
- 글꼴: Segoe UI / Malgun Gothic 시스템 sans, 수식은 Cambria. 별도 원격 폰트 없음.
- 크기: hero 84px, title 50~56px, key message 64px, body 28~30px, table 23~25px, caption 18~20px, metric 96~120px.
- 간격: 좌우 88px, 상하 60px 이상, 그룹 간 32~48px. 기본 간격 8px 배수. 작은 글자로 과밀을 해결하지 않음.
- 컴포지션: 비대칭 표지, 큰 질문, 평면 비교, 근거 역할 행, 수식 대비, 상태/정보 요구 관계, 제안 구조, 조회 예시 순서, agent 구조, 데이터 표, 실측 숫자, 순위 변화도, 실행 시간, 후속 일정.
- 표현: 카드 반복·그라디언트·그림자·장식 아이콘 제외. 구분선·색·크기·정렬로 위계 구성. 짧은 구절과 리스트 중심.
- 탐색: 이전/다음, 방향키, Home/End, 목차, URL 해시, 전체 화면, 인쇄. 본문 스크롤 없이 한 장씩 표시.
