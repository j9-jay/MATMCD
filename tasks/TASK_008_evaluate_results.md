## 확인 사항
LEMMA_Metrics.py의 고정 rank를 새 실험 결과로 사용하지 않는다. scripts/rca_metrics.py는 원문 세 함수를 그대로 사용하며 rank < K 경계와 비표준 MAPK 정의를 보존한다. TASK_041에서 전체 label/KPI 포함·동점 입력 순서와 표 4의 지표를 확인했다. [승인 설정](../configs/rca_protocol.json)의 현재 활성 PR의 유일 pod는 공개 보조 코드 기준 잠정 평가 노드다. scripts/rca_evaluation.py의 evaluate_case/evaluate_active_cases에 실제 순위 기록을 연결한다. CC는 정확 주입 pod 확인 전 두 후보 순위를 보존하고 단일 점수·전체/부분 집계를 생성하지 않는다. 정답 문의 자료는 LLM/RAG 입력에 넣지 않는다.
