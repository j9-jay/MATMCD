## 확인 사항
- TASK_029의 non-thinking 전환과 TASK_028의 단회 RE 경계 보정을 유지한다. 후속 연결은 원본 ConstrainReasoningLLM의 `<Yes>/<No>` 대소문자를 그대로 사용하는 보정 경로를 포함한다. 원본 파서·확률·설명문은 보존했고 인공 검사를 통과했다. 실제 모델 응답 검증은 남아 있으며 thinking 복귀는 별도 검토 대상이다.
- 로컬 모델 설치 완료와 각 RCA 호출 지점의 연결 완료를 구분한다. 설치·형식 보정·임베딩 등 기존 승인은 유지한다.
- TASK_030의 BGE-M3 dense CPU/FP32/batch 1을 로컬 실행기의 원본 로그 요약/RAG 함수에 명시적으로 연결했다. 공식 진입점 파일은 그대로이며 별도 로컬 실행기를 사용한다. 실제 생성된 로그 요약 자료를 포함한 검증은 남아 있다.
- Serper/Tavily와 CODE-01은 웹 수집 경로를 사용하게 될 때의 조건부 항목이다. 표 4 RCA의 필수 선행 조건으로 간주하지 않는다. 로그 요약의 벡터 검색은 웹 검색과 구분하며, 임베딩을 1번 실험 전용으로 제외하지 않는다.
- 서버는 현재 81,920토큰이며 준비된 로그 입력 278개 모두 수용하고 최대 입력 생성에 성공했다. 후속 RAG/그래프 요청의 길이와 전체 통합은 아직 미검증이다. 입력을 임의로 자르거나 다른 모델로 자동 fallback하지 않는다.
- 로컬 실행 프로필은 기존 선택 seed=42, max_tokens=8192 및 sampling을 명시적으로 재사용한다. 각 단계의 원본 온도는 유지하고 저자 설정과 동일하다고 주장하지 않는다. D05의 준비 로그 검증은 TASK_045에서 완료했고 후속 단계의 실물 적용 가능성은 별도다.
- 원본 OnlyLLMAgent 메서드의 인공 파서 검증과 ConstrainNormalAgent·웹·최종 요약의 실제 통합은 다르다.
- 준비/실행 명령과 출력은 [실행기 문서](../docs/LOCAL_RCA_RUNTIME.md)에 있다. `--run` 명령은 구성했지만 준비 상태가 충족되기 전 즉시 거부되며, 전체 실행에 성공한 명령으로 제시하지 않는다.
