# TASK_032 - 승인된 RCA 입력·정확한 로그 연결

## 목적
기존 승인 전처리의 CSV와 이름이 정확히 대응하는 원본 로그 파일을 실행 작업공간에 연결한다. 데이터 선택이나 전처리 조건은 변경하지 않는다.

## 작업 항목
- [x] CSV·manifest·로그 ZIP의 무결성 확인
- [x] 정확한 template/structured 쌍만 출처별 외부 자산에 원문 그대로 준비
- [x] CSV 5개와 로그 디렉터리 연결·프로필 및 저자 동일성 미확인 기록
- [x] 공식 데이터 로더로 CSV 5개 읽기 검증
- [x] 기존 링크의 재검증 및 원본 소스 보존 확인
- [x] 로그 누락·시간 범위·정답 후보 대응 등 남은 의사결정 근거 기록

## 확인 사항
사용자는 명확한 해결 방안이 있는 남은 작업을 처리하고 기록하도록 요청했다. 이번 작업은 기존 입력의 경로 연결 및 원본 파일 압축 해제이며 pod 제외·유사 이름 매핑·로그 요약·그래프 fitting·RWR·평가는 포함하지 않는다. 원본 로그가 없는 pod도 CSV에 유지한다.

## 결과
CSV 5개와 647쌍/1,294개 로그 파일(44,066,393,230바이트)을 연결했다. 공식 로더 5개 사례와 기존 링크 재검증을 통과했고 공식 소스 37개는 보존됐다. prepare_workspace.py의 경로 검증은 정상 외부 링크를 다시 확인할 수 있도록 부모 경로와 기존 링크 대상 일치를 검사한다. 과학적 함수는 변경하지 않았다.

과거 검증기의 '입력 미연결·Task TODO' 고정 가정도 현재 승인 단계의 정확한 링크 검사와 Task 상태 기록으로 갱신했다. 현재 실제 링크 검사 VERIFIED_PROVISIONAL_LINKS를 통과했고 이전 수치 검증 증거는 보존했다.

[연결 결과](../docs/RCA_INPUT_CONNECTION.md), [실행 증거](../docs/evidence/rca_input_connection_20260925T105701596179Z.json). 로그 누락 정책은 별도 의사결정이며 전체 RCA는 아직 미실행이다.

[최종 준비 변경 점검](../docs/evidence/rca_remaining_tasks_check_20260925T113230923769Z.json)에서 공식 37파일·기존 모델/전처리/경로/범위 설정 해시, CSV·로그 링크 10개, 스크립트 구문·Task 상태·문서 링크를 확인했다. git diff --check도 통과했다. 전체 수치 전처리·대용량 모델 검증을 불필요하게 반복하지 않았고 기존 증거를 보존했다.
