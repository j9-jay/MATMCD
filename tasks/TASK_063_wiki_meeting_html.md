## 목적

현재 Markdown 원고를 보존하면서 스크롤로 미팅을 진행할 수 있는 Wiki 형식의 HTML을 구성한다.

## 확인 사항

Markdown 원고·연구 내용·실험 조건·결과는 변경하지 않았다. 본문의 중복 목차는 왼쪽 탐색 목차로 옮겼다. 외부 폰트나 CDN 없이 로컬에서 열리는 단일 HTML이다. 연결된 PDF·Markdown 근거 파일은 기존 상대 경로를 사용한다.
