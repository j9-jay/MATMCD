# TASK_006 - 외부 자산 연결 및 실행 전 점검

## 목적
하나의 경로 설정으로 외부 자산을 참조하고 실험 실행 없이 준비 상태를 검증한다.

## 작업 항목
- [x] configs/paths.json 생성
- [x] 원본 코드의 상대경로를 유지하는 외부 실행 작업공간 구성
- [x] 파일·해시·누락 입력 점검 스크립트 작성
- [x] 문서와 실제 상태 일치 확인

## 확인 사항
원본 코드의 경로 또는 과학적 동작을 수정하는 우회 구현을 하지 않는다.

## 결과
`configs/paths.json` 한 곳의 자산 경로를 모든 준비 스크립트에서 사용한다. WSL 실행 작업공간에 공식 코드와 실제 확보한 CSV/BIF만 symlink로 연결했다. 누락 CSV나 결과/캐시를 위한 빈 폴더를 미리 만들지 않았다. 사전 점검 결과는 준비 미완료로 보고하며 실제 실험은 호출하지 않는다.
