# TASK_069 - LEMMA-RCA에서 정답 정보를 사용하지 않는 MATMCD 기준선

## 상태

**종료(2026-10-18) — [TASK_070](TASK_070_state_aware_retrieval_experiments.md)으로 대체.** 아래 조사 결과로 LEMMA-RCA는 현재 PC에서 공정한 기준선을 만들기 어렵다고 판단했고, 사용자 결정으로 주 데이터셋을 RCAEval RE2로 바꿨다. 실행·파일 변경은 없었다.

## 목적 (당시)

현재 PC에서 정답 정보를 사용하지 않는 MATMCD 기준선을 LEMMA-RCA로 만든다. 원 논문 수치 일치는 목표가 아니었다.

## 확인한 사실 (2026-10-18, 읽기 전용)

### 원 논문의 후보 필터

- MATMCD §4.3은 REASON(Wang et al. 2023b)을 따라 EVT로 관련 없는 Pod를 걸렀다고만 쓴다. 점수 계산, 자르는 기준, 남은 개수, 최종 목록은 미공개다.
- 표 4는 PR 1개, CC 1개 사례의 순위다. 공식 `LEMMA_Metrics.py`의 순위 목록이 방법마다 2개씩이다(예: PC `[5, 13]`, MATMCD `[2, 7]`).
- 정답 순위를 보고했으므로 논문의 필터에서는 정답이 남았다. 남은 후보 수는 CC 13개 이상, PR 10개 이상이라는 하한만 알 수 있다.
- 논문은 RCA 실행 시간, API 호출 수, 하드웨어를 보고하지 않았다.

### 우리 이상 점수 기준 정답 순위

점수는 30 Pod 선정과 같은 규칙이다: 비상수 채널의 `positive_scores / aligned_rows` 최댓값, 동점은 Pod 이름순(`scripts/run_rca_oracle30.py:51-58`). 저장된 TASK_020 manifest만 읽었다.

| 사례 | Pod 수 | 정답 대응 Pod (잠정) | 순위 | 상위 30 |
|---|---:|---|---:|---|
| PR 20210517 | 208 | `catalogue-8667bb6cbc-hqzfw` | 116 | 제외 |
| PR 20210524 | 207 | `catalogue-85fd4965b7-q8477` | 60 | 제외 |
| PR 20211203 | 218 | `mongodb-v1-64c6b69879-p4wfp` | 178 | 제외 |

- 정답 미사용 상위 30 규칙의 후보 recall은 0/5다. 모두 포함하려면 K ≥ 178이 필요하다.
- PR 20210517·20210524의 "catalogue" 대응은 이전에 검증하지 않은 잠정 대응이다.

### 자원

- 전체 후보: PC는 219노드에서 WSL OOM(D08). 설명 생성만 PR+CC 합계 약 19일 이상(30 Pod 실측 18.67초/호출 기준 하한). 219노드 그래프 설명 프롬프트가 81,920 문맥에 들어가는지는 미측정.
- EVT 점수 계산은 Pod별 독립 계산이라 메모리 위험이 낮고, 5개 사례 모두 TASK_020에서 이미 계산돼 있다.

## 종료 판단

- 정답 미사용 기준선은 후보 recall 0/5로 순위 비교가 불가능하다.
- 전체 후보는 현재 PC로 불가능하다.
- 사용자 방법은 전체 corpus를 대상으로 하므로, 기준선만 후보를 제한하면 비교 조건이 맞지 않는다.
- 사용자 결정(2026-10-18): 전체 후보를 다룰 수 있는 RCAEval RE2로 주 데이터셋을 바꾸고, 연구를 NLP 기여(근거 검색·귀속) 중심으로 재구성한다. 기존 정답 포함 30 Pod 결과는 조건부 분석과 동기 사례로 보존한다.
