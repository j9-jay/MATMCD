# TASK_048 - D08 원본 PC 메모리 부족 처리

## 목적
전체 입력 PC 계산 중 WSL OOM으로 중단된 원인을 보존하고, 과학적 조건을 유지하는 자원 대안을 선택한 후 검증한다.

## 작업 항목
- [x] 기존 계산 세션·프로세스 종료 확인
- [x] 커널 OOM 원문·미완료 보고서 보존
- [x] RAM/swap/디스크와 고정 PC 캐시 구현 확인
- [x] 승인 가능한 구체적 자원 대안/영향 문서화
- [ ] 사용자 선택 기록
- [ ] 승인한 자원 설정만 적용하고 전후 상태 기록
- [ ] 전체 입력 원본 PC/RWR 검증 및 결과 기록

## 확인 사항
[D08 상세](../docs/RCA_PC_MEMORY.md). 권장 A는 WSL RAM8GB 유지·swap16GB/E: 배치와 작업 종료 후 WSL 재시작이다. 전역 설정 변경이므로 아직 미적용이며 승인 대기한다. 충분한 최대 메모리·완료 시간은 미확인이다. 캐시 최적화·Pod/기간 축소·PC 설정 변경으로 자동 우회하지 않는다.

## 결과
PR Depth2 계산 중 세션 종료. 커널 Python OOM/RSS약7.26GiB/해당 프로세스 swap약1.95GiB/시스템 swap 잔여0 확인. 그래프·RWR 결과 없음. CC 미시도. 원본 중단 보고서와 커널 로그 보존 완료. D07 새 로그/RAG는 독립 실행했으나 이후 PR44개 후 중단됨을 TASK_047에서 확인했다.
