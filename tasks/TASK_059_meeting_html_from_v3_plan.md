사용자가 지정한 12개 장의 구조를 유지한 기획서 v3를 실제 미팅 자료로 집필하고, 첨부 NVIDIA 디자인 참고 프롬프트의 시각 원칙을 HTML에 적용한다.

## 확인 사항

기획서를 발표 문안으로 집필했으며 새로운 실험이나 조건 변경은 수행하지 않았다. 기존 v3 기획서는 변경하지 않았다. 7화면 재배열은 재적용하지 않았다. 첨부 자료의 디자인 원칙을 참고했으며 NVIDIA 로고·전용 폰트·상업용 제품 탐색 UI를 복제하지 않았다. 한국어는 시스템 글꼴, 영문은 Arial 기반이며 외부 폰트/CDN에 의존하지 않는다.
