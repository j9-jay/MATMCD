# TASK_043 - 원본 로그 UTF-8 실패 진단과 승인된 읽기 적용

## 목적
원본 바이트·모든 행·이벤트 선택 규칙을 보존하며 원본 UTF-8 읽기 실패를 조사하고, 승인한 제한적 읽기만 적용한다.

## 작업 항목
- [x] 최초 실패·원본 해시·잘못된 UTF-8 바이트 진단
- [x] 426쌍 전체 기본 읽기 완료 — 성공 403, UTF-8 실패 23, 기타 실패 0
- [x] 구체적 A/B 방안 제시 후 사용자 A안 승인 확인
- [x] 손실 없는 읽기/선택 유효성 어댑터 인공 검사 10개 PASS
- [x] 실제 실패 23쌍 순차 처리·원본/최초 실패 보존
- [x] 최종 프롬프트 오류 바이트 0·전체 426쌍 준비 확인

## 확인 사항
A안은 기본 UTF-8 읽기에 실제 실패한 동일 원본에만 surrogateescape를 적용한다. 이벤트 식별/선택 열과 최종 프롬프트에 오류 바이트가 있으면 중단한다. 문자 삭제·대체·인코딩 추측·행/Pod 제외를 하지 않는다. 저자의 실제 파일 revision/읽기 조건과 동일성은 UNCONFIRMED이며 문의는 TASK_018에 남긴다.
