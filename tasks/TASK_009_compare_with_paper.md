# TASK_009 - RCA 논문 결과 비교

## 목적
실제 RCA 평가를 논문 표 4와 대조한다.

현재 실행 범위는 사용자 지정 두 사례다(TASK_044). 결과는 선택 사례의 잠정 로컬 결과로 보고하고, 표 4의 전체 집계를 동일 조건에서 재현했다고 표현하지 않는다. 동일 두 사례에서 MATMCD 기준선과 개선안을 비교하는 것과 논문 수치를 참고로 대조하는 것을 구분한다.

## 작업 항목
- [ ] 데이터·코드 해시와 모델·전처리·로그·RWR 조건 확인
- [ ] 표 4의 MAP@5/MAP@10/MRR/RK 비교
- [ ] 사례·반복·집계 차이와 미확정 조건 명시
- [ ] 차이 원인과 재현 한계 기록

## 확인 사항
논문 수치에 맞추기 위해 구현·조건을 바꾸지 않는다. 표 4의 정확한 사례 선택과 대부분 방법의 반복 규칙은 미공개다.

## 결과
비교 미실행. docs/REPRODUCTION_SPEC.md의 수치는 논문 비교 대상이며 로컬 결과가 아니다.
