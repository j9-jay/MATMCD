# TASK_009 - 논문 결과 비교

## 목적
재현 결과를 본문 표 1~4와 대조하고 차이를 사실대로 기록한다.

## 작업 항목
- [ ] 조건 및 입력 해시 일치 확인
- [ ] 표 1~4 비교
- [ ] 차이 원인과 재현 한계 기록

## 확인 사항
논문 수치에 맞추기 위해 코드·데이터·조건을 변경하지 않는다. 비교 대상은 표 1/2의 Precision/F1/FPR/SHD/NHD, 표 3 절제 실험, 표 4 MAP@5/MAP@10/MRR/RK다. `docs/REPRODUCTION_SPEC.md`에 MATMCD/RE 목표 수치를 논문 인용값으로 기록했다. 실험 조건·코드·데이터 hash와 실행 로그를 함께 검토한다. Efficient-CDLMs는 10회 중 best이며 그 선택 지표, 나머지 반복/평균/분산 규칙은 미공개다. 미확정 조건을 동일 조건이라고 표시하지 않는다.
