# TASK_057 - 전문가 관점 리뷰를 통한 미팅 자료 전면 재기획

## 목적

사용자가 지적한 핵심 메시지 부재·정보 과밀 문제를 해결하기 위해, 전문가 페르소나의 독립 리뷰를 받고 기획서와 HTML을 연구 주장·증거·의사결정 중심으로 다시 작성한다.

## 작업 항목

- [x] 지도교수·RCA 실험 방법론·연구 발표 편집자 관점의 AI 서브 에이전트 3개 독립 리뷰
- [x] 핵심 관측과 해석 한계를 구분한 7개 화면으로 기획서 전면 교체
- [x] 단순 검색 대안과 상태 기반 검색의 추가 효과를 묻는 비교 설계 보완
- [x] 7개 발표 화면·4개 부록·발표자 메모로 HTML 전면 재작성
- [x] 재기획 리뷰의 장애 맥락·정답 비참조 조건 보완 반영

## 확인 사항

사용자가 전문가 서브 에이전트 리뷰를 명시 요청했다. 세 리뷰는 AI 전문 관점 검토이며 실제 외부 교수나 연구자의 검토를 받은 것으로 표현하지 않는다. 원래 시험 결과·설정·코드·저자 문의 이력은 바꾸지 않는다. 새 비교는 미팅에서 제시하는 안이며 실행하지 않는다.

### 독립 리뷰와 반영

- 지도교수 관점: 연구 발견이 10번째 화면에 묻히고 작업량이 진척을 대신함 → 첫 화면을 근거 전달 누락·다음 검증 중심으로 바꿈.
- 방법론 관점: 근거 누락·공개 프롬프트 문제·oracle30 후보를 단일 원인처럼 나열 → 관측과 교란 조건을 분리. 단순 Pod별 검색과 상태 기반 검색의 비교를 제안함.
- 편집 관점: 화면당 약 829~2,121자, 스크롤되는 긴 문서 → 본문 7개 16:9 화면과 별도 부록 A~D. 주장은 크게, 상세 수치·조건·이력은 부록으로 이동.
- 재기획 재리뷰: NFS→MongoDB→서비스 영향의 맥락과 평가 Pod/물리 원인을 본문에 명시. 단순 검색 대안도 증상·후보 가설로 질의를 만들고 평가 정답을 참조하지 않도록 표시.
