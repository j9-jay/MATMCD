# TASK_044 - RCA 실행·평가를 두 사례로 변경

**TASK_045 후속:** 현재 문맥 81,920/all/FP16, 준비 로그 278개 수용과 최대 입력 실제 생성 1건 완료. 기존 16,384/미적용/D05 문맥 초과 상태를 대체한다. 전체 Pod·두 사례를 유지했고 실제 RAG/그래프/전체 RCA는 미수행이다. [검증 결과](TASK_045_validate_context_81920.md).

## 결과
[설정 변경 전후·범위 및 준비본 검사](../docs/evidence/rca_two_case_scope_20260926T075701648365Z.json). configs/scope.json을 단일 활성 선택 기준으로 유지하고 inputs.json의 CSV/로그/근거 매핑과 평가 protocol을 두 사례로 제한했다. 실행·평가 profile은 two_cases_v2로 구분한다. evaluate_active_cases는 모든 활성 사례의 동일 단계 기록만 허용하며 제외 사례나 일부 사례만의 집계를 거부한다. 대표 문맥 검사 경로도 제외 사례를 읽지 않도록 선택 기준을 적용했다. 공식 코드는 수정하지 않았다.

| 활성 사례 | Pod 후보 | 정확 로그 쌍 | 로그 부재 Pod | 최대 입력 토큰 | 출력 포함 최소 문맥 |
|---|---:|---:|---:|---:|---:|
| PR 20211203 | 218 | 154 | 64 | 65,073 | 73,266 |

선택 사례의 세 단계 방향쌍 호출은 518,124회, 로그 요약 278회와 RAG는 별도다. 이전 831,396회는 세 사례의 이력이다. 실행 시간은 아직 실측하지 않았다.

[누락 로그 경로 검사 27개](../docs/evidence/rca_log_policy_20260926T075840888460Z.json), [평가/프로토콜 검사 25개](../docs/evidence/rca_approved_protocol_20260926T075841254852Z.json). PR 20220606 재도입과 부분 집계를 거부하고, PR 잠정 점수와 CC 두 후보 순위·점수 보류를 유지했다. 인공 검사이며 실제 실험/평가 결과가 아니다.

PR 20220606의 CSV·로그·근거 manifest·기존 프롬프트/실패·작업공간 링크는 삭제하지 않았다. 선택 사례 내부 CSV 값/열/기간·Pod·모델·seed·sampling·출력·D01~D04 규칙도 유지한다. 재현 조건의 저자 동일성은 UNCONFIRMED다.
