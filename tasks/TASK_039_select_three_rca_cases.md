# TASK_039 - RCA 실행 범위를 세 사례로 변경

**이력 문서:** 이 Task의 3사례 선택은 이후 [TASK_044](TASK_044_select_two_rca_cases.md)의 두 사례 선택으로 대체됐다. 당시 결과와 제외 자산 보존 기록은 유지한다.

## 목적

사용자가 PC 사양을 고려해 지정한 PR 20211203·PR 20220606·CC 20231207만 현재 실행·평가 대상으로 선택한다. PR 20210517·PR 20210524는 현재 범위에서 제외하고 자료·준비 이력은 보존한다.

## 작업 항목

- [x] 사용자 선택을 configs/scope.json 한 곳에 기록
- [x] 활성 CSV·로그·D01 근거 manifest 매핑을 세 사례로 제한
- [x] 연결·사전 점검·D01 도구에 동일 사례 선택 적용
- [x] 선택된 데이터/후보/근거 보존 및 제외 사례 비선택 검증 — 범위 검사 39개, 선택 사례 D01 검사 33개 PASS
- [x] 실행·평가·비교 Task와 D02의 현재 파일 크기 갱신

## 확인 사항

사례 수만 줄인다. 각 사례의 전체 기존 시간 구간, pod 후보, 메트릭 값, 로그 선택 규칙, D01 부재 처리, 모델은 유지한다. D02 분할 읽기 자체는 이번 승인에 포함하지 않는다. 보관한 5개 사례의 준비 기록과 현재 활성 3개를 구분한다. 새 결과를 논문 표 4 전체 집계와 동등한 재현으로 표시하지 않는다.

## 결과

configs/scope.json의 rca_case_selection을 단일 선택 기준으로 구성했다. inputs.json의 CSV·로그·D01 근거 매핑과 expected_rca_inputs는 세 사례만 포함한다. scripts/rca_case_scope.py를 연결/작업공간/사전 점검/D01/입력 검증에서 공통 사용하여 제외 사례를 다시 활성화하는 오래된 입력 매핑은 오류로 중단한다. 과거 5개 준비 기록을 읽더라도 선택한 사례의 메타데이터를 먼저 고른 후 파일을 검사한다.

| 현재 포함 사례 | pod 후보 | 정확한 로그 쌍 | 로그 부재 pod | 로그 전체 GB | 최대 파일 GB |
|---|---:|---:|---:|---:|---:|
| PR 20211203 | 218 | 154 | 64 | 4.19 | 1.16 |
| PR 20220606 | 228 | 148 | 80 | 6.63 | 1.58 |
| CC 20231207 | 196 | 124 | 72 | 4.63 | 1.24 |
| 합계 | 642 | 426 | 216 | 15.45 | 1.58 |

GB는 10^9바이트 기준이다. 전체 연결 로그는 15,448,143,547바이트, 가장 큰 파일은 1,576,968,813바이트다. KPI는 사례마다 1개로 위 pod 수에서 제외한다. 사례별 후보·전체 기존 시간 구간·CSV 값·로그 파일·D01 정책을 바꾸지 않았다.

[범위 검사 39개 PASS](../docs/evidence/rca_three_case_scope_20260925.json): 정확한 사용자 목록/순서, 중복·누락 거부, 제외 CSV/근거 매핑 재도입 거부, 보관 manifest 해시/파일 존재·크기, 원래 전처리 명세와 구현 해시, 변경 스크립트 8개 구문을 확인했다. 제외 CSV·로그 본문은 다시 읽지 않았다.

[선택 사례 D01 검사 33개 PASS](../docs/evidence/rca_log_policy_20260925T125049357248Z.json): 활성 CSV 3개 SHA256·후보/순서·로그 426쌍/부재 216개, 기존 근거 manifest 재사용과 작업공간 연결, 원본 코드 37개 보존을 확인했다. 최초 5개에 대한 이전 44개 검증 보고서도 보존했다.

제외한 PR 20210517/20210524의 원본 ZIP·CSV·로그·D01 manifest와 과거 연결 기록을 삭제하지 않았다. 작업공간의 과거 링크도 보존하지만 현재 실행 목록으로 사용하지 않는다. 기존 prepare_provisional_rca.py와 5개 입력 준비 명세는 과거 실행 해시 보존을 위해 그대로 두고 재실행하지 않았다.

공식 LEMMA_experiment.py는 scope.json을 읽지 않고 기본 20210517을 사용하므로 직접 실행 안내를 제거했다. 원본 파일은 유지하며 실제 로컬 실행기는 TASK_024에서 위 범위 검사를 연결해야 한다. 실행·평가·비교 Task 007/008/009는 세 사례만 대상으로 하며, 정답/집계 미확정 및 NOT_READY 상태는 유지한다. 실제 실험·평가·로그 요약은 실행하지 않았다.
