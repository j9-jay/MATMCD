# TASK_022 - Graphviz A안: 저자 버전 확인·전환 검토

## 목적

B안의 로컬 설치와 별개로 저자가 사용한 Graphviz·렌더링 환경을 확보하고, 필요하면 원본 환경으로 전환할 수 있도록 관리한다.

## 작업 항목

- [x] B안과 저자 동일성 확인을 별도 작업으로 구분
- [ ] TASK_018 일괄 문의를 통해 저자 환경 자료 확보
- [ ] 저자의 dot -V, 배포 패키지/OS·아키텍처·빌드, Graphviz 의존성·폰트·플러그인 확인
- [ ] 현재 B안과 저자 환경의 차이 및 전환 필요성 기록
- [ ] 전환이 필요하면 구체적인 패키지·영향 범위·보존/복원 계획을 제시하고 승인받기
- [ ] 승인된 전환 또는 버전 일치 확인 후 검증 결과 기록

## 확인 사항

2026-09-24 사용자는 B안을 적용하되 A안을 나중에 진행할 수 있도록 별도 기록할 것을 요청했다. 이 Task는 향후 전환 설치나 메일 발송의 선행 승인이 아니다. 문의 발송·답변 관리는 [TASK_018](TASK_018_author_clarifications.md)과 연결한다.

요청 자료: 전체 환경 export, 패키지 관리자 버전 정보, dot -V, 당시 PNG 또는 동일 DOT 입력의 출력 예시, 폰트/렌더링 backend. 배포 패키지 버전과 dot이 보고하는 upstream 버전을 구분한다.

저자 버전과 B안이 같으면 불필요하게 재설치하지 않는다. 다르면 B안의 패키지 해시·설치 로그·검증 PNG를 먼저 보존하고 버전 차이와 호환성을 확인한다. 기존 소스·데이터·수치 결과를 덮어쓰지 않는다. 환경 분리 또는 교체 방식은 확보한 실제 버전에 따라 제안한다.

전환 검증은 같은 인공 행렬로 공식 시각화 함수를 호출해 PNG 생성, 노드·간선 표현, 입력 행렬 보존과 기존 Python/과학적 라이브러리 보존을 확인한다. 이미지 배치·폰트 차이만으로 인과 그래프나 RCA 결과가 달라졌다고 판단하지 않는다. 수치 결과 재실행 필요성은 실제 영향 근거를 확인한 후 별도로 결정한다.

## 결과

저자 버전 미확인. [TASK_021 B안](TASK_021_install_system_graphviz.md)은 2026-09-24 설치·검증을 완료했다. 현재 기준은 Ubuntu graphviz=2.42.2-9ubuntu0.1, dot -V 출력 2.43.0 (0), Python graphviz=0.20.3/pydot=4.0.0이다. 9개 시스템 패키지의 URL·버전·해시는 [보존 lock](../docs/evidence/graphviz_ubuntu_packages.lock.json)에 있다.

A안은 TODO로 유지한다. B안이 로컬에서 동작한다는 사실을 저자 버전 확인 완료로 간주하지 않는다. 저자에게 보낼 관련 질문은 TASK_018 초안에도 반영했으며 메일은 발송하지 않았다.
